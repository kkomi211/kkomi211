**Role:** 팀장 (Team Leader), Backend & Frontend <br>
**Period:** 2025.10.20 ~ 2025.11.10 <br>
**Stack:** Java, Spring Boot, Vue.js, Oracle, WebSocket <br>

**협업 주도:** Git Flow 전략을 도입하고, 하루 2회 병합(Merge) 규칙을 제안하여 충돌을 방지하고 코드 품질을 유지했습니다. <br>

### 2. DEEPSHIELD (딥페이크 방지 및 탐지 솔루션)
**Role:** 팀원 (Team Member), Core Logic Developer <br>
**Period:** 2025.03.25 ~ 2025.11.18 <br>
**Stack:** Python, Flask, PyTorch, NumPy <br>

**비가시성 워터마크 구현:** 이미지에 DWT(이산 웨이블릿 변환)를 2단계 적용하여 눈에 보이지 않는 주파수 영역에 워터마크를 삽입했습니다. <br>
**이미지 무결성 검증:** 딥페이크로 인한 변형 발생 시 워터마크 추출을 통해 조작 여부를 검증하는 로직을 완성했습니다. <br>
**기술적 문제 해결:** 초기 적대적 공격(Adversarial Attack) 방식의 한계를 파악하고, 팀원들과 협의하여 현실적인 워터마킹 기술로 전환해 프로젝트를 완수했습니다. <br>

📂 [GitHub Repository 바로가기](https://github.com/sableye988/Deep_Shield_combined)

### 3. MusicMate (음악인들을 위한 소셜 플랫폼)
**Role:** 개인 프로젝트 (Solo Developer)<br>
**Period:** 2025.11.20 ~ 2025.11.28 <br>
**Stack:** React, MUI, AWS EC2<br>

**SPA 환경 구축:** React-Router-Dom을 활용하여 페이지 새로고침 없는 부드러운 UX를 제공했습니다.<br>
**지도 API 활용:** Kakao Map API를 연동하여 합주실 위치를 시각화하고, useEffect 내에서 API 호출 및 리소스 정리를 최적화했습니다. <br>
**기능 통합:** 밴드 매칭, 중고 거래, 피드 등 다양한 기능을 하나의 플랫폼에서 유기적으로 동작하도록 설계했습니다.<br>
